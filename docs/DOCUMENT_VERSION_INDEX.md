## 🏷️ Version Numbering System

### Format: `v[Major].[Minor]`

**Major Version (v1.0, v2.0, v3.0):**
- Complete rewrites
- Major feature additions
- Breaking changes
- Fundamental restructuring

**Minor Version (v1.1, v1.2, v2.1):**
- Content updates
- Small improvements
- Additional sections
- Clarifications

**Examples:**
- `v1.0` → Initial version
- `v1.1` → Updated with new examples
- `v2.0` → Complete rewrite with new approach
- `v3.0` → Major cleanup/reorganization
