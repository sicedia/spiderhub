## 🎓 Lecciones Aprendidas

### Best Practices Confirmadas
1. ✅ Usar `{% blocktrans trimmed %}` para textos largos
2. ✅ Usar comillas simples dentro de `{% trans '...' %}` para atributos HTML
3. ✅ Preservar HTML tags dentro de traducciones
4. ✅ Usar slugs (no labels) como keys de diccionarios
5. ✅ Compilar con gettext oficial (no scripts custom)

### Áreas de Atención
1. ⚠️ Textos largos en español son típicamente 15-20% más largos
2. ⚠️ Tooltips necesitan verificación de ancho en diseño responsive
3. ⚠️ Emojis pueden no renderizar en todos los navegadores antiguos

## 📞 Comandos para Mantenimiento

### Agregar Nuevas Traducciones
```powershell
# 1. Agregar gettext al PATH
$env:PATH += ";C:\Program Files\gettext-iconv\bin"

# 2. Activar virtualenv
.\pyspider\Scripts\Activate.ps1

# 3. Extraer mensajes nuevos
python manage.py makemessages -l es --ignore=pyspider/* --ignore=node_modules/*

# 4. Editar archivo
# Editar locale/es/LC_MESSAGES/django.po
# Agregar traducciones a los msgstr ""

# 5. Compilar
python manage.py compilemessages --ignore=pyspider --ignore=node_modules

# 6. Reiniciar servidor
python manage.py runserver 8001
```

### Verificar Cobertura
```powershell
# Buscar strings sin traducir
Select-String -Pattern 'msgstr ""' locale\es\LC_MESSAGES\django.po

# Contar mensajes traducidos
(Select-String -Pattern '^msgid "' locale\es\LC_MESSAGES\django.po).Count
```
